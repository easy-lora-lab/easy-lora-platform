# EasyTune 结题论文与实验材料

[阅读论文正文](EasyTune结题论文初稿.md) · [阅读完整测试问答](实验记录与完整问答.md)

论文题目为《面向单卡环境的轻量化语言模型微调与对比验证平台设计与实现》。正文包含中英文摘要、八章研究内容、参考文献、系统架构图及实际推理截图。作者、单位与项目编号保留待填写项。

本目录的实验材料来自2026年11月3日完成的本地实验。Qwen3.5-0.8B工单任务为0/7→3/7，Qwen3.5-2B情感分类为6/6→6/6，RWKV7-G1L-1.5B纠错任务为6/6→5/6。三组任务和训练规模不同，不能据此进行模型能力排名。正文中的三张改善截图均来自Qwen3.5-0.8B。

`assets/`保存论文配图；`data/`保存合成训练数据与已执行测试题；`实验结果.json`保留两侧实际输出和评分；`数据文件校验清单.json`用于核对数据文件。完整问答附录收录全部19道题，包括持平及未通过案例。RWKV准备的24条纠错训练数据中，本轮实际使用前8条。

转换论文为Word时，请保留本目录结构，并以本目录作为图片资源目录。文中公式采用LaTeX数学表示，图表使用编号标题。
